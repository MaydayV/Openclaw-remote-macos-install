配置 Tailscale

📱 你的电脑
请先在你的电脑上配置 Tailscale
brew install tailscale
sudo tailscale up
tailscale ip -4
💻 朋友的 Mac
让朋友在他的 Mac 上执行相同的命令
brew install tailscale
sudo tailscale up
tailscale ip -4
✅ 完成后
朋友会获得一个 Tailscale IP（例如 100.64.1.2），记下这个 IP

使用屏幕共享

📱 让朋友执行以下步骤：
  • 打开"系统设置"
  • 进入"通用" → "共享"
  • 开启"屏幕共享"
  • 点击"生成链接"按钮
  • 将生成的链接发送给你
🔗 收到链接后
打开链接，你就能控制朋友的屏幕了。然后打开终端，手动执行安装命令。
npm install -g openclaw
openclaw init
openclaw gateway start
